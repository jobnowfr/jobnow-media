# jobnow-media

Visuels et vidéos des réseaux sociaux de JobNow (jobnow.fr), générés et programmés chaque jour par Claude.
La routine est décrite dans RUNBOOK.md. Les outils de rendu sont dans tools/ (les six styles visuels dans tools/styles/), le contenu de chaque jour dans content/ (modèle : content/exemple.json).

Polices, toutes libres (voir les licences dans tools/fonts/) : Bricolage Grotesque, JetBrains Mono, Shantell Sans, Playwrite FR Trad, Anton, Archivo, Courier Prime, Syne, Jersey 10 et Jersey 15 sous licence SIL Open Font License 1.1 ; Special Elite sous licence Apache 2.0.
